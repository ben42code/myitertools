# Security Policy

## Supported versions

While the project is pre-1.0, only the **latest release** on
[PyPI](https://pypi.org/project/ben42code.myitertools/) is supported. Fixes ship
in a new release; there are no backports to earlier `0.x` versions.

## Reporting a vulnerability

Please report privately through GitHub —
[**Report a vulnerability**](https://github.com/ben42code/myitertools/security/advisories/new)
(Security tab > Advisories). Do not open a public issue for something you
believe is exploitable.

Useful in a report: the version, the Python version, and a snippet that shows
the behaviour.

This is a hobby project maintained by one person: expect an acknowledgement
within a few days, not hours. If a report is valid, the fix and the advisory are
published together.
